# Deep Learning: From Neural Network Fundamentals to Modern AI

## 📌 Project Overview

A comprehensive AI-powered research and learning project developed using **Google NotebookLM**.

This notebook explores the field of Deep Learning, starting from neural network fundamentals and extending towards modern Artificial Intelligence. It brings together multiple learning resources in a single organised research workspace, using NotebookLM's capabilities to explore, analyse and interact with the collected information.

## 🎯 Project Objectives

- Explore Deep Learning concepts, from foundational neural networks to modern AI.
- Organise and integrate multiple learning resources into one research notebook.
- Experiment with different source formats and types.
- Explore the capabilities of Google NotebookLM Studio.
- Experience AI-powered research, knowledge organisation and interactive learning.
